# UAV Cloud API

## Description

The launch of Cloud API is primarily targeted at developers who do not require deep customization of apps,
allowing them to directly use UAV Robotics' drones to communicate with third-party cloud platforms. This enables
developers to focus on the development and implementation of cloud service interfaces.
